# Flores Amarillas

Un pequeño ritual digital: escribes tu nombre, respondes tres preguntas con calma y al final nace una flor amarilla con un mensaje.

## Cómo correrlo

```bash
pnpm install
pnpm dev --port 43123
```

Abre [http://127.0.0.1:43123](http://127.0.0.1:43123).

## Scripts

| Comando | Descripción |
| --- | --- |
| `pnpm dev` | Servidor de desarrollo |
| `pnpm build` | Build de producción |
| `pnpm start` | Servir el build |

## Stack

Next.js, React, TypeScript y Tailwind CSS.
